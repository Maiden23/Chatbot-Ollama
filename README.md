# Chatbot-Ollama with LangChain & Streamlit

[![Python]](https://www.python.org/)
[![Streamlit](https://img.shields.io/badge/Built%20with-Streamlit-FF4B4B?logo=streamlit&logoColor=white)](https://streamlit.io)
[![LangChain](https://img.shields.io/badge/LangChain-Framework-yellow)](https://www.langchain.com/)
[![License: MIT](https://img.shields.io/badge/License-MIT-green.svg)](https://opensource.org/licenses/MIT)

A simple conversational chatbot built using **LangChain**, **Ollama**, and **Streamlit**, powered by a local language model like `gemma3`.

---

## Features

- Natural language chatbot using **Ollama**
- Prompt chaining with **LangChain**
- Interactive web UI via **Streamlit**
- Secure config with `.env` for API keys
